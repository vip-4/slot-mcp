# 九款机台机制手册

赔付单位约定：

* 固定线机台：`pays[n]` = **单线注**倍数（单线注 = 总注 / 启用线数）
* Ways 机台：`pays[n]` = **每通路注**倍数（每通路注 = 总注 / ways）
* `scatter_pays[n]`、Hold & Win 赏金 = **总注**倍数

---

## 1. 幸运水果机 `lucky_fruits`

| 项 | 值 |
| --- | --- |
| 结构 | 3 轴 × 3 行，固定 5 线（3 横 + 2 斜） |
| 符号 | 🍒樱桃 🍋柠檬 🍉西瓜 🍇李子 🔔铃铛 7️⃣幸运7；⭐ Wild |
| 赔付 | 2 连：樱桃/柠檬 1x线注、西瓜 2x线注；3 连：5 / 8 / 11 / 19 / 24 / 30 / 60（Wild） |
| 特性 | `GambleConfig`：中奖后红/黑二选一，最多 5 次，上限 1000x 总注 |
| 主题 | 复古水果（暗红机台） |
| 实测 | RTP 97.08%，命中率 75.4%，波动率 1.47，最大 18.4x |

**设计要点**：最经典的「低波动入门机台」，靠高频小奖维持节奏；
博彩是中性期望（胜率 0.5）的额外玩法，不改变 RTP 但显著提升留存感。

## 2. 糖果狂欢 `candy_carnival`

| 项 | 值 |
| --- | --- |
| 结构 | 5 轴 × 3 行，固定 20 线 |
| 符号 | 🍭棒棒糖 🍬软糖 🍩甜甜圈 🍫巧克力 🍰蛋糕 🎁礼物盒；🌈 Wild；🧁 Scatter |
| 赔付 | 3/4/5 连递增（如礼物盒 7 / 25 / 67x线注）；Scatter 3/4/5 个 = 2/10/50x总注 |
| 特性 | `ExpandingWildConfig`：Wild 落在**第 3 轴**时整轴扩展为 Wild，并赠送 1 次锁轴重转 |
| 主题 | 糖果乐园（粉紫配色） |
| 实测 | RTP 97.04%，命中率 67.5%，波动率 1.61，最大 50.1x |

**设计要点**：扩展 Wild 用配置描述为「符号 + 轴列表 + 重转次数」，
引擎侧不需要知道「糖果」这个概念；重转时其余轴重新采样，扩展轴以粘性 Wild 保留。

## 3. 龙宫探宝 `dragon_palace`

| 项 | 值 |
| --- | --- |
| 结构 | 5 轴 × 4 行，固定 50 线（由 `generate_lines(5,4,50)` 确定性生成） |
| 符号 | 🏮宫灯 🪙铜钱 🌸莲花 💰金锭 🐲龙瞳；🐉 神龙 Wild；🏯 Scatter |
| 赔付 | 3/4/5 连（如龙瞳 5.1 / 19.5 / 77x线注） |
| 特性 | 免费旋转：3/4/5 Scatter → 10/14/20 次；倍率递进 `[1,2,3,4,4,5,6,7,9,12,...]`；<br>第 3 轴 Wild 在特性内**粘性保留**；再触发 3/4/5 → 4/8/12 次；使用独立条带 `fs` |
| 主题 | 深海龙宫（青绿 + 金） |
| 实测 | RTP 97.20%，命中率 58.4%，波动率 8.79，最大 718x，触发 1/167 局 |

**调参经验**：粘性 Wild 让收益随免费旋转次数**高度非线性**增长
（10 次 → 12 次即可让特性 RTP 翻数倍），因此调节时应优先小步改动倍率递进表。

## 4. 法老之墓 `pharaoh_tomb`

| 项 | 值 |
| --- | --- |
| 结构 | 5 轴 × 3 行，全盘 **243 Ways** |
| 符号 | ☥生命符 👁荷鲁斯之眼 🪲圣甲虫 🐈巴斯特猫 👑法老面具；🐺 阿努比斯 Wild；<br>🪙金币（BONUS，不参与 Ways）；🟢MINI 🔵MINOR 🟣MAJOR（JACKPOT） |
| 赔付 | Ways 按相邻轴计数，3/4/5 连（如法老面具 69.6 / 350 / 1395x每通路注） |
| 特性 | Hold & Win：全盘 ≥8 个赏金符号触发；3 次重转计数，每次出现新符号重置；<br>赏金：金币 0.9x、MINI 7.8x、MINOR 19.8x、MINOR 以上…；MAJOR 64.4x；铺满 15 格额外 207x |
| 主题 | 金字塔秘境（金棕配色） |
| 实测 | RTP 95.40%，命中率 49.8%，波动率 8.53，最大 519x，触发 1/346 局 |

**实现要点**：BONUS / JACKPOT 类符号被 `evaluator` 排除在 Ways 结算之外，
只参与特性，避免「既是线奖又是奖池」的重复派彩；`prize_symbols` 用重复元素近似权重
（如 `["coin"] * 8 + ["mini","minor","major"]` ≈ 73% 金币）。

## 5. 星际远征 `star_expedition`

| 项 | 值 |
| --- | --- |
| 结构 | 6 轴 × 4 行，全盘 **4096 Ways** |
| 符号 | ☄️陨石 💫彗星 🛰️卫星 🪐行星 🛸飞碟 🚀火箭；🌟 星门 Wild；🌌 黑洞 Scatter |
| 赔付 | 3/4/5/6 连（如火箭 83.5 / 255 / 922 / 2534x每通路注） |
| 特性 | 级联：每次中奖后符号消失、上方补位继续结算，倍率 +1 封顶 10x；<br>免费旋转：3/4/5/6 Scatter → 8/12/16/25 次，级联倍率**每轮重置**（标准做法） |
| 主题 | 深空远征（深蓝 + 青） |
| 实测 | RTP 95.78%，命中率 80.7%，波动率 4.21，最大 245x，触发 1/170 局 |

**调参经验**：4096 Ways 下几乎每格都可能形成连线，级联链会很长，
因此单格赔率必须比固定线机台小 1~2 个数量级——这是 Ways + 级联机台最常见的调参坑。

## 6. 锦鲤纳福 `fortune_koi`

| 项 | 值 |
| --- | --- |
| 结构 | 5 轴 × 3 行，固定 20 线（`LINES_20_5x3`） |
| 符号 | 🐟锦鲤 🪙金元宝 🏮灯笼 🪭折扇 🎀中国结 🎴福袋；🌊 锦鲤 Wild（**同时是收集者**）；🪷 莲花 Scatter；🟤铜钱 / ⚪银锭 / 🟡金元宝币 / 🎁福袋大奖（币值符号，不参与线赔） |
| 赔付 | 3/4/5 连递增（如锦鲤 5 / 17 / 48x线注，Wild 7 / 24 / 72x线注）；Scatter 3/4/5 = 2/10/40x总注 |
| 特性 1 | **随机 Wild 投放** `RandomWildConfig`：每局新鲜网格按权重投放 0~3 枚 Wild（62/28/8/2），基础与免费旋转均生效，不覆盖 Scatter 与币值 |
| 特性 2 | **Cash Collect** `CollectConfig`：出现锦鲤 Wild 时收集屏上全部金币面值（铜钱 0.11x / 银锭 0.55x / 金元宝币 2.2x，福袋大奖 7x），免费旋转内收集倍率 ×2 |
| 特性 3 | **免费旋转** `FreeSpinsConfig`：莲花 3/4/5 → 8/12/16 次，倍率递进 [1,1,2,3,5]，可再触发（3/4/5 → 4/6/8 次），专用条带币值更密 |
| 主题 | 锦鲤池塘（墨绿 + 金） |
| 实测 | RTP **96.76%**，命中率 67.9%，波动率 4.70，最大 188.9x，免费旋转 1/62.6 局，再触发 1/422 局 |
| 贡献拆分 | 线赔 ≈47%、收集 ≈43%、Scatter 直付 ≈6% |

**调参经验**：

1. 币值符号不参与线赔（`kind=bonus`），但会占格子、稀释连线概率——币值越密，线赔 RTP 越低，两边要一起调。
2. 收集以**总注**计，线赔以**线注**计（20 线 → 线注 = 总注/20），差一个数量级；币值面额写错一位就会把 RTP 拉到几百个百分点。
3. 稀有币用「权重 0」在基础条带里屏蔽（只在免费条带出现）：引擎中权重 ≤ 0 表示该符号不在该轴出现。
4. `collect` 只对新鲜网格结算，避免级联派生网格让同一枚币被重复收取。

## 7. 雷霆神殿 `thunder_temple`

| 项 | 值 |
| --- | --- |
| 结构 | 5 轴 × 3 行，固定 20 线（`LINES_20_5x3`） |
| 符号 | 🦅雷鹰 🐺苍狼 🐦渡鸦 🔱长矛 🛡️盾牌 🔯符文；🔨 雷锤 Wild ×2、⚡ 雷锤 Wild ×3；🏛️ 神殿之门 Scatter；🗿 雷石（选宝触发，不参与线赔） |
| 赔付 | 3/4/5 连递增（雷鹰 3.7/11.3/29.7x线注）；Wild 自带线赔；Scatter 3/4/5 = 1.5/6/25x总注 |
| 特性 1 | **倍率 Wild** `MultiplierWildConfig`：×2 / ×3 雷锤参与替代时按 `combine=sum` 合并（×2 + ×3 → ×4），线与 Ways 都生效；合并方式可切 `max` / `sum` / `product` |
| 特性 2 | **Pick'em 选雷石** `PickBonusConfig`：雷石 3/4/5 枚 → 可挑 3/4/5 次，**有放回**抽取奖品（火花 0.5x / 雷石 1.5x / 雷霆 4x / 雷神之怒 15x，总注倍数），累计派奖 |
| 特性 3 | **免费旋转** `FreeSpinsConfig`：神殿之门 3/4/5 → 10/15/20 次，倍率递进 [1,2,3,5]，可再触发 5/8/12 次 |
| 主题 | 雷霆神殿（深蓝 + 雷金） |
| 实测 | RTP **96.99%**，命中率 51.5%，波动率 6.03，最大 358.9x，免费旋转 1/137 局，再触发 1/828 局 |
| 贡献拆分 | 线赔 ≈79%、选宝 ≈15%、Scatter 直付 ≈6% |

**调参经验**：

1. `unique=False`（有放回）时单次挑选期望固定，奖品数不受挑选次数限制；
   `unique=True` 且「可挑次数 ≥ 奖品数」会让奖励变成**确定值**，失去随机性——配置校验会拦截这种组合。
2. 选宝以**总注**计：奖品面额 1x 就等于「白送一注」，触发频率 1% 时贡献就是 1%×奖品均值×次数；
   面额写大一位会瞬间吃掉几十个百分点 RTP。
3. Pick'em 与 Cash Collect 一样只对**新鲜网格**结算，避免级联重复派发。

## 8. 巨神遗迹 `colossal_ruins`

| 项 | 值 |
| --- | --- |
| 结构 | 5 轴 × 3 行，固定 20 线（`LINES_20_5x3`） |
| 符号 | 🗿石像 🐆美洲豹 🎭黄金面具 🔥火把 🏺陶罐 🍃藤叶；🌞 图腾 Wild；🚪 遗迹之门 Scatter |
| 赔付 | 3/4/5 连递增（石像 3.1/10.1/26.5x线注）；Scatter 3/4/5 = 1.8/7/24x总注 |
| 特性 1 | **巨符号** `ColossalSymbolConfig`：每局结算前先在网格里投放一个 **2×2 或 3×3** 的同符号方块（石像 / 美洲豹 / 面具 / Wild，权重 12/10/8/3），尺寸权重 `{0:25, 2:55, 3:20}`（0 = 本局不投放），落点限制在最左轴 1~3、最上排 1~2，撞到 Scatter 则放弃投放 |
| 特性 2 | **免费旋转** `FreeSpinsConfig`：遗迹之门 3/4/5 → 8/12/16 次，倍率递进 [1,2,3]，可再触发 4/6/8 次 |
| 主题 | 巨神遗迹（丛林石构 + 金） |
| 实测 | RTP **96.31%**，命中率 49.0%，波动率 3.56，最大 165.5x，免费旋转 1/74.7 局，再触发 1/233 局 |
| 贡献拆分 | 线赔 ≈95%、Scatter 直付 ≈5% |

**调参经验**：

1. 巨符号是「先改网格、再结算」的算子：它铺满相邻轴排，会**同时抬高**多条线的命中，
   因此赔付表要按实测整体缩放（`colossal_ruins` 首轮线赔达 1.42，赔付表整体 ×0.63 才落回目标）。
2. 块尺寸受网格约束（3×3 只能落在能容纳它的轴/排），配置校验会拦截越界；
   尺寸键 `0` 表示「本局不投放」，用于调节投放频率。
3. `protected_symbols` 保护 Scatter / 币值：块内撞到受保护符号时**整块放弃**，避免破坏触发判定。

## 9. 凤凰涅槃 `phoenix_rebirth`

| 项 | 值 |
| --- | --- |
| 结构 | 5 轴 × 3 行，固定 20 线（`LINES_20_5x3`） |
| 符号 | 🪶火羽 🔴赤玉 🪞青铜镜 📜卷轴 🪔香炉 🌫️余烬；🔥 涅槃之火 Wild；🌳 神木 Scatter；🥚 凤凰蛋（**占位符号，bonus 类型，本身不赔付**） |
| 赔付 | 3/4/5 连递增（火羽 17.5/55.4/145.8x线注，Wild 21/64/169x线注）；Scatter 3/4/5 = 1.5/6/22x总注 |
| 特性 1 | **神秘符号** `MysterySymbolConfig`：屏上的凤凰蛋在结算前统一揭示为同一符号（火羽 18 / 赤玉 22 / 青铜镜 26 / 卷轴 22 / 香炉 12 / Wild 10），可切 `reveal_all_same=False` 逐格独立揭示 |
| 特性 2 | **免费旋转** `FreeSpinsConfig`：神木 3/4/5 → 8/12/16 次，倍率递进 [1,2,3]，可再触发 4/6/8 次；免费条带里蛋的权重从 3~4 提到 7~8 |
| 主题 | 凤凰涅槃（暗红 + 火金） |
| 实测 | RTP **96.92%**，命中率 51.3%，波动率 4.03，最大 186.8x，免费旋转 1/91.4 局，再触发 1/721 局 |
| 贡献拆分 | 线赔 ≈97%、Scatter 直付 ≈3% |

**调参经验**：

1. 占位符号必须是 `kind=bonus`：它本身不赔付，一旦忘记设置就会**堵住赔付线**
   （配置校验已强制这条约束）。
2. 神秘符号是「转化率」玩法：它对 RTP 的影响正比于**占位符号密度 × 揭示目标的赔付水平**，
   `phoenix_rebirth` 实测把线赔从 0.101 抬到 0.160（+58%），
   剩下缺口靠赔付表缩放补齐（本台最终按 ×5.86 缩放后落在 96.9%）。
3. `reveal_all_same=True` 时只消耗 1 个随机数（前后端同构的关键点），
   改成 False 后 RNG 消耗会随蛋的数量变化，必须两侧一起改。
